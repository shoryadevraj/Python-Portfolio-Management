# Portfolio Management System

A complete Portfolio Management System developed using Python Flask, SQLite, HTML, and CSS.

This project allows users to create, update, share, and export professional portfolios. It also includes an Admin Dashboard to manage all portfolios.

---

# Features

## User Features

- Create Portfolio
- View Portfolio
- Update Portfolio
- Share Portfolio Link
- Export Portfolio as PDF
- Go Live Portfolio Page

## Admin Features

- Secure Admin Login
- View All Portfolios
- Total Portfolio Count
- Manage User Portfolios
- Delete Portfolios

---

- HTML5
